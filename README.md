# NerdStuff
Just a link to cool nerd stuff 

firecrawl/firecrawl
Category: Web Scraping
API/library that turns websites into clean, LLM-ready markdown and structured data. Built so AI agents can crawl, search, and extract web content without brittle scrapers.
https://github.com/firecrawl/firecrawl

bytedance/UI-TARS
Category: GUI Agent
Research project for agents that operate UIs by seeing the screen and taking actions. Aims at automated GUI interaction with native agent models rather than hand-written scripts.
https://github.com/bytedance/UI-TARS

Panniantong/Agent-Reach
Category: Agent Scraping
CLI that lets AI agents read/search platforms like Twitter, Reddit, YouTube, and GitHub without paid APIs. Framed as free agent infrastructure for web/social content access.
https://github.com/Panniantong/Agent-Reach

facebookresearch/brain2qwerty
Category: Brain Decoding
Research code that reconstructs typed sentences from non-invasive MEG/EEG signals. Uses a CNN encoder, transformer, and character-level language model for brain-to-text decoding.
https://github.com/facebookresearch/brain2qwerty

ruvnet/RuView
Category: WiFi Sensing
Turns commodity WiFi RF into spatial awareness: presence, pose-like signals, and vital-sign style monitoring without cameras. Targets IoT/home-automation style spatial intelligence.
https://github.com/ruvnet/RuView

sherlock-project/sherlock
Category: OSINT Tool
Looks up a username across many social networks to find matching accounts. Common OSINT/recon CLI for username hunting.
https://github.com/sherlock-project/sherlock

666ghj/MiroFish
Category: Swarm Simulation
Multi-agent “swarm intelligence” engine aimed at forecasting and social/public-opinion style prediction. Uses LLM agents plus knowledge-graph style memory for simulation.
https://github.com/666ghj/MiroFish

tashfeenahmed/freellmapi
Category: LLM Gateway
Single OpenAI-compatible /v1 endpoint that routes across many free LLM providers with failover. Meant for personal experimentation, not production billing.
https://github.com/tashfeenahmed/freellmapi

camel-ai/oasis
Category: Agent Simulation
Open framework for large-scale social simulations with LLM agents (up to ~one million). Used to study AI societies and agent interaction dynamics.
https://github.com/camel-ai/oasis

PurpleDoubleD/locally-uncensored
Category: Local AI
Desktop all-in-one local AI studio: chat, image/video generation, and a coding agent. Offline-oriented, no Docker/cloud required on Windows/Linux.
https://github.com/PurpleDoubleD/locally-uncensored

agent0ai/agent-zero
Category: AI Agent
General-purpose autonomous AI agent framework/assistant. Designed to run tools and complete open-ended tasks with minimal hardcoding.
https://github.com/agent0ai/agent-zero

eracle/OpenOutreach
Category: Sales Agent
Self-hosted AI SDR for B2B lead gen: finds ICP fits, explains why, and emails from your mailbox. CLI/agentic outreach automation.
https://github.com/eracle/OpenOutreach

eleutherai/pythia
Category: Model Research
EleutherAI hub for interpretability and learning-dynamics work around the Pythia model suite. Focused on studying how LLMs train and what they learn, not an end-user app.
https://github.com/eleutherai/pythia

Wan-Video/Wan2.2
Category: Video Generation
Open large-scale video generative models (Wan series). Used to create/generate video from generative AI pipelines.
https://github.com/Wan-Video/Wan2.2

cheaper-inference/OmniRoute
Category: LLM Gateway
MIT AI gateway that exposes one endpoint across hundreds of providers/models with quota-aware fallback. Aimed at coding agents (Cursor, Claude Code, etc.) plus token-saving routing.
https://github.com/cheaper-inference/OmniRoute
